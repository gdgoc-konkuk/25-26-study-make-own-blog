## **1. 프로젝트 개요**

- **프로젝트명:** i-log
- **목표:** 기록과 복습을 통해 **UI/UX 디자인 능력과 개발 지식**을 효율적으로 성장시키는 아카이빙 블로그 구축
- **핵심 가치**
    - **가독성(Clarity)**: 학습 내용의 시각적 명확성. / **이용 편리성(Usability)**: 정보 접근의 직관성
    - 첫 도전을 위한 **미니멀리즘** 디자인. 복잡한 기능과 장식을 덜어내고 콘텐츠 자체에 집중
- 특이사항
    - UIUX는 가능한 만큼 최고점을 높일 생각 . .
    - 인공지능 선생님과 함께 하는 바이브 코딩

## **3. 주요 기능 정의**

1. **블로그 기능**
    - 코드 공부
        - 프론트/백엔드 학습 개념 정리
        - 알고리즘 문제 풀이 및 해설
    - 3D & Art
        - Unity/Unreal/Blender 튜토리얼 및 실험 과정
        - UI/UX디자인 원칙 분석 및 적용 사례
    - 자격증 준비 과정
        - 웹디자인 기능사, 컴퓨터그래픽스 운용기능사, 데이터 자격증 (과목별 요약 및 시험 후기)
    - 포트폴리오
        - 프로젝트별 개요, 목표, 기여도 및 결과물 시각 자료 정리 페이지
2. **공통 기능**
    - **검색**
        - 태그 및 키워드 기반의 기본 검색 기능
        - 1차 개발에 포함 MVP 필수 기능)
    - **카테고리/태그**
        - 주제별 분류 및 태그를 통한 정보 필터링
        - 이용 편리성 확보
    - **작성자 관리**
        - 글 작성, 수정, 초안 저장 기능 (관리자 페이지)
    - **소통 (선택)**
        - Disqus 등 외부 서비스 연동을 통한 댓글 기능
        - 2차 개발 고려, 1차는 Static 목표)

## **4. 기술 스택**

| **구분** | **기술 스택** | **선택 이유** |
| --- | --- | --- |
| **개발 방식** | **정적 사이트 생성기 (SSG, Static Site Generator)** 방식 | 첫 개발이므로 서버 관리 부담이 적고, 속도가 빠르며 비용이 저렴함. |
| **프론트엔드** | HTML5, CSS3, JavaScript (기본) | SSG 기본 스택. 복잡한 SPA 프레임워크는 2차 개발 이후 고려. |
| **SSG 도구** | **Jekyll (또는 Hugo)** | 블로그 제작에 특화되어 있으며, 테마를 활용하여 빠르게 MVP 구축 가능. |
| **배포/호스팅** | **GitHub Pages** | 완전 무료이고 Git 학습과 연동되어 1차 프로젝트 목표에 적합. |
| **마크업** | Markdown | 코드 및 텍스트 작성의 편리성 (가독성 확보에 유리) |

## **6. 일정 계획**

- **개발 1차**
    1. SSG 환경 구축 및 기본 테마 적용. 
    2. **필수 기능 구현** (포스팅, 카테고리/태그). 
    3. **최소 가독성 및 반응형 디자인** 확보. 
    4. GitHub Pages 최초 배포 완료.
- **개발 2차**
    1. 커스텀 디자인 적용 및 UI/UX 개선. 
    2. **검색 기능** 고도화. 
    3. 외부 서비스 연동 (댓글/통계). 
    4. 포트폴리오 전용 페이지 구현.
