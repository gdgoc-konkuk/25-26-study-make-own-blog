## **3. 주요 기능 정의**

1. **기술 블로그 기능**
   - Notion API 기반 글 동기화
   - 카테고리, 태그 기반 글 목록 제공
   - 검색 기능 지원
2. **About Me 기능**
   - “나”라는 개발자에 대한 소개(성격, 활동, 경력 등)
   - 프로젝트를 줄 글 형태로 소개 (기술스택, 기여 부분(자세히))
   - 클릭 시 상세 페이지 이동 (회고록, 프로젝트 자세한 소개, 프로젝트 깃허브?)
3. **프로젝트 모아보기 기능**
   - About Me 탭에 프로젝트 칸에 있을 예정
   - 프로젝트 카드 형태로 전시 (썸네일, 기간)
   - 클릭 시 상세 페이지 이동 (GitHub/배포 링크/프로젝트 소개 글)
4. **공통 기능**
   - 상단 네비게이션 바 (Blog / About Me)
   - 성능 최적화 (이미지 최적화, 캐싱, CDN)

## **10. 프로젝트 관리 & 컨벤션**

- **형상 관리 전략**: Git Flow (main / develop / feature)
- **Git Commit 컨벤션 (Conventional Commit)**
  - Feat: 새로운 기능 추가
  - Fix: 버그 수정
  - Desing: CSS 등 사용자 UI 디자인 변경
  - Docs: 문서 수정
  - style: 코드 포맷팅 (비즈니스 로직 변경 없음)
  - Refactor: 리팩토링
  - Comment: 주석 추가 또는 변경
  - Chore: 빌드/패키지 관리 변경
  - Rename: 파일 또는 폴더 이름 수정/이동만 수행한 경우
  - Remove: 파일 또는 폴더 삭제만 수행한 경우
- **작업 방식**:
  1. 이슈 생성 → 브랜치 생성(feature/#이슈번호-작업내용)
  2. PR 생성
  3. develop에 머지
  4. 버전 관리를 통해 main에 release PR로 머지 예정
