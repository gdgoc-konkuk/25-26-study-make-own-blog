# 디자인 피드백 세션

## ☀️ 날짜

2025.11.10 (Mon)

## 📜 내 작업 요약

- Figma Make를 통해 초기 구상했던 무채색 계열의 깔끔한 디자인 생성
- Variables, Styles, Components, etc 공부 및 홈페이지에 적용
- 개발 환경 셋업

## 📜 내 작업 내용 중 가장 인상깊었던 부분 & 가장 배움이 컸던 부분

- 피그마를 사용하여 디자인을 수정해본 경험이 처음이라 걱정됐지만 초기 세팅을 잘 하면 어렵지 않게 진행할 수 있을 것 같다.
- 깃허브 마일스톤을 처음 써보게 될 것 같은데 이슈만 쓸 때와 비교하면 초기 목표 달성에 더 도움이 될 것 같다.

## 📜 정윤아님 작업 내용 중 인상깊었던 부분

- 피그마 프로토타입을 활용해서 트랜지션을 시각화한게 인상적이었다.
- 블로그 만들 때는 다양한 트랜지션을 활용하지는 않겠지만 추후 다른 프로젝트 디자인을 하게 된다면 도전해보고 싶다.

## 📜 최준서님 작업 내용 중 인상깊었던 부분

- 자몽과 기타 색상, 아이콘을 포인트로 사용하는게 인상적이었다.

- 반응형 작업 하게 되면 물어봐야지
