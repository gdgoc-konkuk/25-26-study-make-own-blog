# 만나블 1차 회고록_김석진

**날짜**

2025.10.27

## **📜 내 작업 요약**

아무것도 준비되어 있지 않은 무에서 유를 창조하는 것이다 보니, 어떻게든 끌고가서 완성을 해보자는 생각을 갖고 기획해보자. 기획도 처음, 디자인도 처음, 필요하다면 DB 구축을해야하나, 이 또한 처음인 상태에서 어떤 컨셉을 갖고, 내가 어떤 가치에 중점을 두고 블로그를 개발할지 생각해본 시간이었다.

## **1. 프로젝트 개요**

- **프로젝트명 : 미정**
- **목표 :** 나만의 블로그인만큼 스스로 작성한 글들을 아카이브 형식으로 모아두고, 최종적으로 이 블로그의 도메인 하나가 포트폴리오 그 자체가 될 수 있도록 하기
- **핵심 가치**
    - UX 중심의 카테고리 설계로 직관적인 글 탐색
    - 카테고리 예: Algorithm / Study / Tech / Project
    - 기술적 성장의 기록이자 개발자로서의 정체성을 표현하는 포트폴리오

---

## **2. 요구사항 분석**

### **사용자 요구사항**

- 글을 등록, 수정, 삭제할 수 있어야 함
- 카테고리별 글 분류 및 검색 가능
- 태그별 탐색 기능
- 모바일/데스크탑 반응형 지원
- 메인 화면에 자기소개 및 포트폴리오 링크 노출

### **시스템 요구사항**

- SSR(서버 사이드 렌더링) 기반 페이지 로딩 최적화
- 정적 페이지 생성(SSG) + 동적 라우팅 지원
- CI/CD 자동 배포 (GitHub Actions + Vercel)
- Markdown 기반 콘텐츠 렌더링
- SEO 최적화(meta 태그, sitemap, RSS 피드)

---

## **3. 주요 기능 정의**

1. **블로그 기능**
    - 게시글 목록 / 상세 보기
    - 카테고리별 글 필터링
    - 검색 기능 (제목 + 태그 기반)
    - 마크다운 포맷 글 렌더링
    - 다크모드 지원
2. **공통 기능**
    - 반응형 UI
    - 헤더 / 푸터 / 네비게이션 바
    - 소셜 미디어 링크 연결
    - 메타 태그 자동 생성 (Next.js Head 활용)

---

## **4. 기술 스택**

| 구분 | 기술 |
| --- | --- |
| **Frontend** | Next.js, TypeScript, Tailwind CSS |
| **Backend (콘텐츠 관리)** | Contentlayer 또는 Sanity.io (Headless CMS) |
| **Database (opt…)** | SQLite / Supabase (필요 시 댓글, 조회수 등) |
| **Deployment** | Vercel |
| **Version Control & CI/CD** | GitHub + GitHub Actions |
| **Package Manager** | pnpm |
| **Etc.** | ESLint, Prettier |
